Secuencias de Escape
\’     Mostrar comillas simples dentro de una cadena en la salida de información
\”     Mostrar comillas dobles dentro de una cadena en la salida de información
\\     Barra invertida, o diagonal inversa, es para mostrar una back slash
\n     Salto de linea
\r     Retorno
\t     Tabulación
\b     Retroceso
\f     Salto de pagina
